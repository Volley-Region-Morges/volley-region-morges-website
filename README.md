# Volley Région Morges - Site Web

Bienvenue sur le site web officiel de **Volley Région Morges**, l'association de volleyball de la région de Morges en Suisse romande.

## À propos

Volley Région Morges est une association dynamique dédiée à la promotion et au développement du volleyball dans la région de Morges. Nous accueillons les joueurs de tous niveaux, des débutants découvrant le sport jusqu'aux compétiteurs expérimentés.

## Contenu du site

Le site propose une structure simple et intuitive :

- **Accueil** : Page d'introduction avec message de bienvenue
- **À propos** : Informations sur l'association
- **Équipes** : Présentation de nos trois équipes principales
- **Contact** : Coordonnées pour nous joindre

## Structure du projet

```
volley-region-morges-website/
├── index.html       # Page principale du site
├── styles.css       # Feuille de styles
└── README.md        # Ce fichier
```

## Fichiers

### `index.html`
Page HTML principale contenant la structure complète du site :
- En-tête avec titre et slogan
- Navigation sticky (collante)
- Sections principales : Accueil, À propos, Équipes, Contact
- Pied de page

### `styles.css`
Feuille de styles CSS contenant :
- Variables de couleur (bleu et orange)
- Mise en page responsive
- Navigation sticky
- Grille pour les cartes d'équipes
- Design mobile-first

## Couleurs utilisées

- **Bleu primaire** : `#1e40af` - Pour les en-têtes et éléments principaux
- **Orange secondaire** : `#f97316` - Pour les accents et survols
- **Gris clair** : `#f8fafc` - Pour les fonds alternés

## Fonctionnalités

✅ Design responsive (adapté aux mobiles, tablettes et ordinateurs)  
✅ Navigation sticky facilitant l'accès aux sections  
✅ Cartes d'équipes avec effet au survol

## Comment utiliser

1. Clonez ce repository
2. Ouvrez `index.html` dans votre navigateur web
3. Le site s'affichera avec tous les styles appliqués
